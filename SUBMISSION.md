## Name

SPECULATE — regression investigation room

## Short description

A checkout returns the wrong total. SPECULATE gives two investigators a shared record of real checks so new evidence can change what they do next. The developer gets an evidence-linked explanation and a standalone test file they can rerun after a fix.

## How Mozaik is used

Pricing and Tax are concurrent participants in Mozaik 4.0.5. They can probe the same local checkout and read each other's observations. When new peer evidence arrives after a participant has prepared its next action, a Mozaik action-boundary interceptor gives it a chance to reconsider before that action executes. The run records the old action, the resulting action and the referenced evidence. This does not interrupt a model response already being generated.

The same tools and total request limit support a single investigator and a two-investigator control without that reconsideration step. The comparison retains failed runs and ties.
